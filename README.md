# Ansible Island Adventure

This edition has 40 scored cards. Thirty-seven use Ansible or Ansible Automation Platform. Three short game activities give your crew a chance to meet and solve an island word puzzle. The original SQL and route-math puzzles are [optional bonuses](workshop/bonuses.md).

Open the VS Code terminal in your assigned Showroom and clone the public repository.

```bash
cd ~
git clone https://github.com/agilleyrh/ansible-island-adventure.git
cd ansible-island-adventure
```

Follow the field guide and submit answers on the live workshop board. [Field guide](workshop/field-guide.md) · [Workshop board](https://island-island-adventure.apps.cluster-lwl8f.dyn.redhatworkshops.io/)

The [cards](workshop/challenges.md) use VS Code, three RHEL hosts, rootless Podman, automation controller and Event-Driven Ansible. Your edits stay in your own clone. Controller and EDA sync `main` from the same public repository.

Adapted from AnsibleCTF Island Adventure by Joon Paik and Red Hat contributors.
